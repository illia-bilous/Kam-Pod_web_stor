Новий квест

Додай сторінки: картинка + заголовок + текст (+ цитата).

Додай сцени: картинка + репліки персонажів.

Оберіть гру за назвою і баштою. Координати вежі підставляються самі — їх можна змінити. Картинки стискаються автоматично.

Якщо "Широта"/"Довгота" порожні — геозона не активна, місце не рахуватиметься як "відкрите".

Не біля об'єкта? Відкрий Google Maps → знайди місце → натисни правою кнопкою (на телефоні — довге натискання) на потрібну точку → скопіюй координати з підказки → встав у поля "Широта"/"Довгота" вище.
